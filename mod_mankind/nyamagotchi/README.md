## Nyamagotchi

ID мода: MANKIND_NYAMAGOTCHI

### Описание мода

Добавляет функциональный кошко-тамагочи, за которым нужно следить, иначе он "погибнет".
Тамагочи может кушать, играть и отдыхать по желанию его владельца.
Издает звуки при взаимодействии, есть возможность их заглушить.
